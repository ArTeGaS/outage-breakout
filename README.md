# Графік відключень

Невеликий браузерний арканоїд у вигляді графіка відключень.

**[Грати](https://artegas.github.io/outage-breakout/)**

Два оформлення — DTEK і Київ Цифровий. Для кожного є світла й темна тема. Вибір зберігається в браузері.

## Керування

- Миша, палець або ← → — рух платформи.
- Пробіл — запуск або пауза.
- F — повний екран, якщо браузер його підтримує.
- ↻ — нова гра.

## Локальний запуск

Потрібен Node.js 22 або новіший. Встановлення залежностей не потрібне.

```sh
npm start
```

Відкрити `http://127.0.0.1:4173`. Перевірка логіки: `npm test`.

Перевірка браузера: `node scripts/browser-qa.mjs` із доступним пакетом `playwright`. За потреби змінні `PLAYWRIGHT_MODULE` та `CHROMIUM_PATH` задають шляхи до вже встановлених Playwright і Chromium. Знімки та результати пишуться в ігнорований Git каталог `output/playwright`.

Перевірка тем і адаптивного поля: `node scripts/layout-qa.mjs`. Зміна висоти екрана та сенсорне керування: `node scripts/viewport-qa.mjs`. Політ кульки після оновлення: `node scripts/flight-qa.mjs`.

Сайт працює на звичайному статичному хостингу, без сервера, аналітики та звернень до сервісів енергопостачання. GitHub Pages публікує корінь гілки `main`.

## Оформлення й ліцензія

Неофіційний некомерційний проєкт, не пов’язаний із ДТЕК або сервісом «Київ Цифровий». Графік ігровий і не показує актуальних даних.

Гра використовує характерні кольори та клітинки графіків: [ДТЕК](https://www.dtek-kem.com.ua/ua/shutdowns) і [Києва Цифрового](https://kyivcity.gov.ua/news/yak_ne_propustiti_povidomlennya_pro_vidklyuchennya_elektroenergi_v_kiv_tsifrovomu_onovili_adresi_ta_lokatsi_cherg_u_servisi_dtek_svitlo/). Темне оформлення DTEK — авторська адаптація. Іконки намальовані заново, оригінальні логотипи та скріншоти не включені до репозиторію.
